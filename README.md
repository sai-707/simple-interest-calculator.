# Simple Interest Calculator

A simple Bash script designed to calculate simple interest based on user inputs.

## Project Description
This project provides an easy-to-use command-line interface for calculating simple interest. It accepts input parameters from the user—specifically the **Principal Amount**, **Annual Rate of Interest**, and **Time Period in years**—and computes the total simple interest accrued along with the total final amount.

## Formula
Simple Interest ($SI$) is calculated using the standard formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal Amount
- **R** = Annual Rate of Interest (in percentage)
- **T** = Time Period (in years)

## Input Fields
- **Principal ($P$):** The initial amount of money deposited or borrowed.
- **Rate ($R$):** The percentage rate of interest per year.
- **Time ($T$):** The duration for which the money is borrowed or invested (in years).
